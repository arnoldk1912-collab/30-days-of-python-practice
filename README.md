## How to Run the Files

1. Activate the virtual environment:

```bash
source /Users/macbook/Desktop/VS\ CODE/VS\ CODE.PY/.venv/bin/activate
```

2. Open the project folder:

```bash
cd "/Users/macbook/Desktop/VS CODE/VS CODE.PY"
```

3. Run any Python script from the practice folder:

```bash
cd "30 Days of python"
python3 "Dictionaries 30 days of python.py"
```

You can replace the file name with any script you want to practice.
